### 2. Swipe навігація (мобільні) 📱
**Статус**: ✅ Готово

#### Що додано:
- **Swipe вгору** ⬆️ — наступний місяць
- **Swipe вниз** ⬇️ — попередній місяць
- Мінімальна відстань: 50px
- Запобігання випадковим swipe

#### Як працює:
1. Користувач торкається календаря
2. Проводить пальцем вгору або вниз
3. Якщо відстань > 50px — місяць змінюється
4. Календар оновлюється

#### JavaScript:
```javascript
// Touch events
touchstart → зберегти початкову позицію
touchmove → відстежити рух
touchend → обчислити відстань і змінити місяць
```

---

### 3. Scroll навігація (десктоп) 🖱️
**Статус**: ✅ Готово

#### Що додано:
- **Прокрутка вниз** — наступний місяць
- **Прокрутка вгору** — попередній місяць
- Працює з колесом миші
- Поріг чутливості: 10px

#### Як працює:
1. Користувач наводить курсор на календар
2. Прокручує колесо миші
3. Якщо |deltaY| > 10px — місяць змінюється
4. Календар оновлюється

#### JavaScript:
```javascript
// Wheel event
wheel → перевірити deltaY → змінити місяць
```

## 📊 Технічні деталі

### Додані події:

#### Touch Events (мобільні):
```javascript
touchstart → { passive: true }
touchmove → { passive: true }
touchend → { passive: true }
```

#### Wheel Event (десктоп):
```javascript
wheel → { passive: false } // preventDefault()
```

### Додані CSS властивості:
```css
touch-action: pan-y;
user-select: none;
```

### Змінні JavaScript:
