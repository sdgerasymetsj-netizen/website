2. **Функція видалення записів для викладачів**:
   - Викладач тепер може видаляти **тільки свої** записи
   - При наведенні на свій запис з'являється кнопка "🗑️ видалити"
   - Інші записи (інших викладачів) залишаються недоступними для видалення
   - Адміністратор як і раніше може редагувати всі записи

### Як це працює:
- Викладач заходить в систему зі своїм логіном
- На сторінці "Бронювання" бачить всі записи
- Якщо запис зроблений ним, з'являється червона кнопка "🗑️ видалити"
- При кліку на кнопку з'являється підтвердження
- Після підтвердження запис видаляється

### Технічні деталі:
- Додано перевірку `isMyBooking` в коді рендерингу
- Додано обробник події для кнопки видалення
- Використовується `data-booking-id` для ідентифікації запису
