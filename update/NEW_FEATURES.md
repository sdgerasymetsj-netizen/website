# Нові функції системи бронювання 🎉

## 1. Інтерактивна навігація по датах

### Стрілки навігації
- **← Стрілка вліво**: Перехід на попередній день
- **→ Стрілка вправо**: Перехід на наступний день

### Клік на дату
- Натисніть на кнопку з датою (наприклад, "Вівторок, 28.04.2026")
- Відкриється календар для швидкого вибору будь-якої дати

### Клік на місяць
- Натисніть на кнопку з місяцем (наприклад, "Квітень 2026")
- Відкриється вибір місяця для швидкого переходу

## 2. Фільтр аудиторій

### Кнопка "Аудиторія"
- Натисніть на кнопку "Всі аудиторії"
- Відкриється модальне вікно з списком аудиторій:
  - Всі аудиторії
  - Аудиторія 68
  - Аудиторія 81
  - Аудиторія 82
  - Аудиторія 83
  - Аудиторія 68a

### Як працює фільтр:
1. Оберіть конкретну аудиторію
2. Відображатиметься тільки обрана аудиторія
3. Кнопка змінить текст на "Ауд. 68" (наприклад)
4. Кнопка стане помаранчевою (активний фільтр)
5. Щоб скинути фільтр — оберіть "Всі аудиторії"

## 4. Технічні деталі

### Змінні JavaScript:
- `selectedDate` — поточна обрана дата
- `selectedRoom` — поточна обрана аудиторія ('all' або номер)

### Функції:
- `updateDateDisplay()` — оновлює відображення дати та місяця
- `renderBookingGrid(date)` — рендерить сітку бронювань з фільтрацією

### CSS класи:
- `.date-navigation` — контейнер навігації
- `.nav-arrow` — стрілки вліво/вправо
- `.date-btn` — кнопка дати
- `.month-btn` — кнопка місяця
- `.room-filter-btn` — кнопка фільтра аудиторій
- `.room-filter-btn.active` — активний фільтр
