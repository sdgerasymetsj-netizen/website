# Швидкий старт 🚀

## Крок 1: Встановити Node.js

### Windows:
1. Завантажте з [nodejs.org](https://nodejs.org/)
2. Запустіть інсталятор
3. Натисніть "Next" → "Next" → "Install"
4. Перезавантажте комп'ютер

### Перевірка:
Відкрийте командний рядок (cmd) і введіть:
```bash
node --version
```

Має показати щось типу: `v20.10.0`

---

## Крок 2: Встановити залежності

### Відкрийте командний рядок в папці проекту:
1. Відкрийте папку з проектом
2. Натисніть Shift + правою кнопкою миші
3. Оберіть "Відкрити вікно PowerShell тут" або "Відкрити командний рядок тут"

### Введіть команду:
```bash
npm install
```

Зачекайте поки встановляться всі пакети (може зайняти 1-2 хвилини)

---

## Крок 3: Запустити сервер

### Введіть команду:
```bash
npm start
```

Має з'явитися:
```
Сервер запущено на http://localhost:3000
```

---

## Крок 4: Відкрити в браузері

### Відкрийте браузер і перейдіть на:
```
http://localhost:3000
```

або просто:
```
localhost:3000
```

## Проблеми?

### Помилка "npm не розпізнано"
- Node.js не встановлено або не додано в PATH
- Перезавантажте комп'ютер після встановлення Node.js

### Помилка "Cannot find module 'express'"
- Запустіть `npm install` ще раз

### Порт 3000 зайнятий
- Змініть порт в `server.js`:
  ```javascript
  const PORT = 3001 // Змініть на інший порт
  ```

### Дані не зберігаються
- Перевірте, що сервер запущений
- Перевірте консоль браузера (F12) на помилки
