## 🚀 Як використовувати

1. **Навігація по днях**:
   - Натисніть ← для попереднього дня
   - Натисніть → для наступного дня

2. **Вибір дати**:
   - Натисніть на кнопку з датою
   - Оберіть дату в календарі

3. **Вибір місяця**:
   - Натисніть на кнопку з місяцем
   - Оберіть місяць

4. **Фільтр аудиторій**:
   - Натисніть "Всі аудиторії"
   - Оберіть потрібну аудиторію
   - Для скидання оберіть "Всі аудиторії"
